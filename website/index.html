Entwickelt für echtes Hosting

Alles, was du für moderne Minecraft-Server und -Netzwerke brauchst – intuitiv, sicher und ohne unnötigen Ballast.

1-Click

Modrinth Modpacks

Such direkt im Panel nach Fabric-Modpacks (.mrpack). Lodestone lädt Mods, Konfiguration und Loader automatisch mit SHA-1 Prüfsummen herunter.

Auto

Netzwerk-Autoconfig

Verbinde Server mit einem Velocity-Proxy. Das Panel schreibt Velocity-Secrets, Forwarding, Serverlisten, Join-Reihenfolge (Try) und Forced Hosts vollautomatisch.

Kein Port-Forwarding

playit.gg Integration

Mache deine Server ohne Router-Zugriff oder offene Ports weltweit erreichbar. Der Node-Daemon steuert den playit-Tunnel direkt per Docker.

CodeMirror 6

Moderner Dateimanager

Syntax-Highlighting für YAML, JSON, TOML, XML und Properties. Upload per Drag & Drop, Verschieben, Entpacken von ZIP/TAR.GZ und Bulk-Aktionen.

Voice Chat

Simple Voice Chat

1-Klick Aktivierung pro Server. Das Panel installiert die Erweiterung, öffnet den UDP-Port und konfiguriert den Host automatisch für alle Spieler.

Sicher

Docker-Isolation & Rollen

Server laufen als Non-Root mit Speicher- und CPU-Limits. Feingranulare Rollen pro Projekt (Eigentümer, Admin, Operator, Betrachter) mit Argon2id.

In wenigen Minuten einsatzbereit

Wähle deine bevorzugte Bereitstellungsmethode. Alle Daten bleiben lokal auf deinem Server.

# 1. Repository klonen
git clone https://github.com/Henny263462/lodestone.git
cd lodestone

# 2. Konfiguration anlegen & Secrets eintragen
cp .env.example .env
# Trage LODESTONE_ADMIN_PASSWORD und DOCKER_GID in .env ein

# 3. Datenverzeichnis vorbereiten
sudo mkdir -p /srv/lodestone && sudo chown 1000:1000 /srv/lodestone

# 4. Stack starten
docker compose up -d --build

# Öffne http://localhost:8480 im Browser
# Schnelle Bereitstellung ohne Source-Build via GitHub Container Registry
curl -LO https://github.com/Henny263462/lodestone/releases/latest/download/docker-compose.release.yml
curl -L  https://github.com/Henny263462/lodestone/releases/latest/download/.env.example -o .env

# .env anpassen & Verzeichnis anlegen:
sudo mkdir -p /srv/lodestone && sudo chown 1000:1000 /srv/lodestone

# Container starten:
docker compose -f docker-compose.release.yml up -d

Häufig gestellte Fragen

Alles rund um Kompatibilität, Selbsthosting und Lizenz.

Welche Minecraft-Server-Software wird unterstützt?
Lodestone unterstützt Paper, Purpur, Folia, Fabric, Vanilla sowie Velocity (als Proxy). Das Panel ermittelt Builds, Prüfsummen und passende Java-Versionen (Java 8 bis Java 22+) vollautomatisch.
Wie funktioniert die Modrinth-Modpack Integration?
Beim Erstellen eines Servers wählst du einfach den Tab "Modrinth-Modpack". Lodestone lädt die .mrpack-Datei direkt von Modrinth, verifiziert alle SHA-1/SHA-512 Prüfsummen, entpackt die Server-Overrides und startet den Fabric-Server.
Brauche ich zwingend eine Portfreigabe?
Nein! Wenn du deine Server zuhause oder hinter CGNAT betreibst, kannst du die integrierte playit.gg-Funktion nutzen. Du trägst deinen geheimen Schlüssel unter "Nodes" ein, und Lodestone startet den Tunnel-Agenten automatisch im Docker-Netzwerk.
Ist Lodestone kostenlos und Open Source?
Ja, Lodestone ist zu 100 % Open Source unter der freien MIT-Lizenz. Es gibt keine versteckten Einschränkungen, keine Telemetrie und keine Lizenzkosten.
Kann ich mehrere physische Maschinen verbinden?
Ja! Auf weiteren Linux-Servern startest du einfach nur das schlanke Image lodestone-node und verbindest es im Panel über die Weboberfläche unter "Nodes" mit IP und Token.
