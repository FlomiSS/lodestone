Minecraft-Server verwalten, ohne Chaos.

Lodestone ist ein Hosting-Panel für einzelne Server und ganze Netzwerke. Konsole, Dateien, Backups, Plugins und Mods von Modrinth – und ein Modpack ist mit einem Klick installiert.

In fünf Minuten starten Quellcode ansehen

Kostenlos · läuft auf deinem eigenen Rechner oder Server · keine Cloud nötig

Alles, was ein Server braucht

  • Modrinth-Modpacks

    Fabric-Modpack suchen, Version wählen, anlegen. Lodestone lädt Mods und Konfiguration herunter, prüft Prüfsummen und zeigt den Fortschritt.

  • Plugins & Mods im Blick

    Zu jeder installierten Datei siehst du Modrinth-Seite, Version, Lizenz und Quellcode. Versionen lassen sich wechseln, Updates mit einem Klick einspielen.

  • Netzwerke mit Autoconfig

    Velocity-Proxy und Server dahinter: Forwarding, Secrets, Serverliste, Join-Reihenfolge und Forced Hosts schreibt das Panel selbst.

  • playit.gg eingebaut

    Freunde einladen ohne Portfreigabe im Router: Der Node startet den playit-Agenten, du trägst die Tunnel-Adresse beim Server ein.

  • Konsole & Dateien

    Live-Konsole mit Farben, Editor mit Syntax-Highlighting, Upload per Drag & Drop, Verschieben, Archivieren, Entpacken und Mehrfachauswahl.

  • Backups & Rechte

    Backups bei laufendem Server, sicheres Wiederherstellen. Mehrere Benutzer mit Rollen pro Projekt, Passwörter mit argon2id, isolierte Container.

Loslegen

Voraussetzung ist ein Rechner mit Docker und Docker Compose.

  1. Herunterladen

    git clone https://github.com/Henny263462/lodestone.git
cd lodestone

  2. Konfigurieren

    cp .env.example .env
# Passwort, Token (openssl rand -hex 32) und DOCKER_GID eintragen
mkdir -p /srv/lodestone && chown 1000:1000 /srv/lodestone

  3. Starten

    docker compose up -d --build

    Dann http://<deine-maschine>:8480 öffnen und mit dem Administrator aus der .env anmelden.

Aus dem Internet erreichbar? Stelle einen Reverse-Proxy mit HTTPS davor. Details stehen in der README.

Häufige Fragen

Was kostet Lodestone?

Nichts. Der Quellcode ist offen (MIT-Lizenz). Du zahlst nur für den Rechner, auf dem es läuft.

Welche Server-Software wird unterstützt?

Paper, Purpur, Folia, Fabric, Vanilla und Velocity. Version, Download mit Prüfsumme und Java-Version werden automatisch bestimmt.

Welche Modpacks funktionieren?

Modrinth-Modpacks (.mrpack) mit Fabric, die auf Servern laufen. Forge und NeoForge folgen später.

Brauche ich eine Portfreigabe im Router?

Nein, wenn du playit.gg nutzt: Den Schlüssel einmal unter „Nodes“ eintragen, im playit-Dashboard einen Tunnel anlegen und die Adresse beim Server speichern.

Ist das sicher?

Rechte werden bei jeder Anfrage serverseitig geprüft, Container laufen ohne Root-Rechte und mit Limits. Der Node-Daemon hat Zugriff auf Docker – betreibe ihn nur im internen Netz oder hinter TLS/VPN. Sicherheitslücken meldest du bitte privat, siehe SECURITY.md.

Lodestone ist ein unabhängiges Projekt und nicht mit Mojang, Microsoft, Modrinth oder playit.gg verbunden. „Minecraft“ ist eine Marke von Mojang AB.
